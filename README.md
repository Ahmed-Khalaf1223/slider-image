# 📸 JavaScript Image Slider

This is a simple interactive **image slider** built using **HTML, CSS, and vanilla JavaScript** — no frameworks or external libraries.

## 🎯 Project Goals

The purpose of this project is to:

- Practice DOM manipulation in JavaScript.
- Handle user interactions using event listeners.
- Dynamically generate pagination indicators.
- Manage slider state and update the UI accordingly.

## ⚙️ Features

- Navigate through images using "Next" and "Previous" buttons.
- Displays current slide number (e.g., "Slide #2 of 5").
- Clickable pagination bullets for direct slide access.
- Buttons are automatically disabled when reaching the first or last slide.
- Smooth image transitions with clean, responsive UI.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
